# lua_afk

Скрипт для SA-MP на Lua (MoonLoader): меню в тёмном стиле, авто спавн, бот дальнобойщик, автообновление.

## Требования
- MoonLoader, SAMPFUNCS
- mimgui (`moonloader/lib/mimgui`)
- SAMP.Lua (`moonloader/lib/samp/events`) — по желанию, для чекпоинтов бота

## Установка
Положите `lua_afk.lua` в папку `moonloader`.

## Команды
- `/lafk` — меню
- `/lafkupd` — проверить обновления
- `/ltruck` — вкл/выкл бота дальнобойщика (для личного сервера, на Arizona RP отключён)

## Автообновление
Скрипт скачивает `lua_afk.lua` из ветки `main` и сравнивает `script_version`.
Проверка: после входа в игру, после каждого перезахода на сервер и каждые 5 минут.

### Как выпустить обновление
1. Измените `lua_afk.lua`.
2. Поднимите версию в `script_version(...)` и `SCRIPT_VERSION`.
3. Обновите строку `-- @changelog: ...` (её текст показывается в окне обновления).
4. Обновите `version.json` (для старых версий скрипта).
