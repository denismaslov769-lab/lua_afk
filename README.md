# lua_afk

Скрипт для **Arizona Role Play** (SA-MP) на Lua для MoonLoader.

## Требования
- MoonLoader
- SAMPFUNCS
- mimgui (папка `mimgui` в `moonloader/lib`)

## Установка
Скачайте `lua_afk.lua` и положите в папку `moonloader` в папке с игрой.

## Команды
- `/lafk` — открыть/закрыть меню
- `/lafkupd` — вручную проверить обновления
- `/ltruck` — включить/выключить бота дальнобойщика (для личного сервера, на Arizona RP отключён)

## Автообновление
После входа на сервер скрипт проверяет `version.json` в этом репозитории.
Если версия там новее установленной, появится окно с кнопками **Обновить** и **Отмена**.

### Как выпустить обновление
1. Внесите изменения в `lua_afk.lua`.
2. Увеличьте версию в `lua_afk.lua` (`script_version` и `SCRIPT_VERSION`).
3. Укажите ту же версию и описание изменений в `version.json`.
